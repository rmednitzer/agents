# harness/

Orchestration, sandboxing, and execution control for agentic workloads. Enforces sandbox boundaries, tool-use authorization, action budgets, and observability.

Surface: `Contract` + `run_under_contract` (preconditions, invariants, postconditions, governance; hard/soft severity) with opt-in L3 wiring (`skill_contracts` composition, `drift_monitor`/`drift_threshold` + `DriftThresholdCrossed`, `RecoveryOutcome.directive`, run-scoped `lifecycles`, `parent_span_id` for a correlated nested-run span tree; opt-in blast-radius authority tiers via `tier_classifier` / `approval_tier` (BL-242, ADR 0029) so a Tier-2-or-above action escalates to REQUIRE_APPROVAL beyond the static `approval_required` list, with the action's tier and a workload-supplied `rollback_planner` plan carried onto the human-facing `ApprovalInterruption` across the replay and deferred paths (BL-251, ADR 0031), and a two-step parameter restatement that runs an irreversible (Tier 3) action only after the human re-enters matching arguments (`approve(restated_arguments=)`, BL-252, ADR 0033); every default reproduces L1/L2); `ActionBudget`/`BudgetTracker` (steps, tokens, wall-clock, tool-calls, per-tool quotas, plus a cost dimension and per-tool token/wall-clock caps, cumulative across an approval pause via `snapshot`/`initial_*`, and prompt-cache hit/creation counters via `consume_cache_tokens`, accounting-only, ADR 0026); `PydanticAIRuntime` (guard gate on local + MCP tool calls, `ResumableState` pause/resume with replay default and opt-in `approval_mode="deferred"` continuation from the paused leg's history so prior tool calls run exactly once, BL-114, ADR 0027, wall-clock watchdog that preempts at an await boundary, streaming budget, opt-in `RetryPolicy` and `soft_reject_as_error`, opt-in `model_settings` pass-through for provider-side prompt-cache breakpoints with the cache counts surfaced onto the tracker, BL-132/BL-171, ADR 0026); structured OTel-ready events + sinks (`OTelSink`, `RedactingSink` for secret/PII scrubbing, an `AccessDeniedEvent` for an `ACLStore` denial); `compose_contracts` (strictest severity on a name collision, including governance); `RecoveryHandler`; `DriftMonitor` (Jensen-Shannon); opt-in run-provenance records (`RunRecord`, `contract_digest`, `verify_run_record`, the `record_sink` keyword, the digest bound in-process at enforcement time, with the `scripts/check_run_records.py` offline gate; plus `RunRecord.degraded`, record schema v1.1.0, the orthogonal quality axis set when a SOFT postcondition is violated on the final delivered leg, BL-244, ADR 0030); deterministic grounding postconditions via `harness/grounding.py` (`ungrounded_citations` plus the SOFT `grounding_predicate(extract, pattern=)` factory, the anti-confabulation check that relabels a run degraded without rewriting model content, BL-244, ADR 0030); and optional provider batch capabilities (`AnthropicBatchProcessor` + `cache_control_system` behind the `anthropic` extra, `OpenAIBatchProcessor` behind the `openai` extra). See [ADR 0007](../docs/adr/0007-l2-implementation-wave.md), [ADR 0008](../docs/adr/0008-l3-security-hardening-and-roadmap.md), [ADR 0010](../docs/adr/0010-l3-default-path-wiring-and-audit-wave.md), [ADR 0011](../docs/adr/0011-third-audit-and-l3-capability-wave.md), [ADR 0012](../docs/adr/0012-run-provenance-and-anthropic-capabilities.md), [ADR 0029](../docs/adr/0029-graduated-authority-tiers.md), [ADR 0030](../docs/adr/0030-degraded-disposition-and-grounding.md), [ADR 0031](../docs/adr/0031-approval-context-payload.md), and [ADR 0033](../docs/adr/0033-two-step-restatement.md).

Connecting a workload to an Anthropic or OpenAI model (provider selection, credentials, the `Runtime` boundary, testing without keys): see [Runtime providers](../docs/runtime-providers.md).

Contract changes here have wide blast radius. Document each contract change in `docs/adr/` and state it in the PR description.
