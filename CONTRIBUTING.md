# Contributing

## Before opening a PR

1. Read [CLAUDE.md](./CLAUDE.md) for repository conventions.
2. Open an issue for non-trivial changes; discuss the contract before coding.
3. Run tests and lint locally where applicable.

## Commit messages

Conventional Commits style (feat:, fix:, docs:, refactor:, test:, chore:, build:, ci:).

## PR description

State:
- What changed.
- Blast radius (which components, which contracts).
- Rollback path.
